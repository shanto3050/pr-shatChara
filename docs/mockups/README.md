# Character mockups

## Bablu (বাবলু): free resources only, 29 October 2026

**Purpose:** see how close free tools get to the Real Cricket 24 benchmark (D17) before deciding on paid tools or an artist (D16).

**How it's made:** `art-source/create_mockup_bablu.py`, run headless in Blender 4.5 LTS.

- Body, skin, eyes, brows, lashes and hair: MakeHuman CC0 assets through the MPFB2 v2.0.18 add-on. Age about 15, broad build, skin tinted toward #9C6440, hair darkened to black.
- Clothing generated by the script from the body's own shape and skinned to the same game rig:
  - Lungi: a tube following the convex outline of both legs, with a waist roll, tuck knot and folded hem, and a procedural blue check texture.
  - Vest (genji): an offset copy of the torso surface plus shoulder straps.
  - Gamcha: a red-and-white checked strip over the left shoulder.
- Light: Poly Haven "Evening Field" HDRI (CC0) plus a warm low sun. Ground uses the project's village-earth texture.
- Renders: Cycles, 128 samples, AgX.

To rebuild: download the assets with `fetch_mockup_assets.py` (needs MPFB2 v2.0.18 in `art-source/vendor/mpfb/` and the HDRI in `art-source/vendor/hdri/`), then run:

```bash
blender -b --factory-startup -P art-source/create_mockup_bablu.py -- --samples 128
```

The `.blend` file and the web 3D model (`.glb`, about 10 MB) are written to `art-source/vendor/` and aren't committed until Git LFS is set up (backlog V00).

### Assessment

| Area | Result |
|---|---|
| Proportions, build, skin tone | Good: believable 15-year-old |
| Rig | Good: one skeleton for body and clothes, ready for Unity and mocap |
| Light | Good, at no cost |
| Face | Smooth and "plastic": no pores, no fine detail. The main gap to the benchmark |
| Clothing | Stiff shapes. Real folds need cloth simulation (Blender's is free) or hand modeling |
| Hair | Helmet-like cap. Needs hair cards |

The renders are offline quality. The in-game real-time look will be somewhat flatter.
