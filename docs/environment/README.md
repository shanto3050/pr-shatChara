# Village props (free resources)

Authentic Bangladeshi village props for the courtyard, built by `art-source/create_village_props.py` in Blender 4.5 with CC0 textures from ambientCG and Poly Haven (sources and SHA-256 in `art-source/village-textures.json`). Leaf, palm-trunk and pump-paint textures are generated by the script. Everything is at real-world scale in metres, with UVs in metres so textures tile at true size.

| Prop | Bangla | Triangles | Notes |
|---|---|---|---|
| Mud house | মাটির ঘর | 11,472 | Raised earthen plinth (ভিটা) with a verandah, mud-plastered walls with a darker base band, wooden door and shutter, corrugated tin gable roof (real corrugation), bamboo posts, dung cakes (ঘুঁটে) drying on the side wall |
| Haystack | খড়ের গাদা | 1,856 | Tall straw dome around a bamboo pole, irregular surface, loose straw at the base |
| Tube well | চাপকল | 656 | Cast-iron hand pump (green paint, rust at edges) on a concrete pad with a drain |
| Bamboo fence | বাঁশের বেড়া | 948 | 4 m section: posts, rails and uneven split-bamboo slats |
| Banana plant | কলাগাছ | 508 | Pseudo-stem and nine torn, drooping leaves |
| Coconut palm | নারকেল গাছ | 4,284 | 7.5 m leaning ringed trunk, 14 fronds with leaflets, a coconut bunch |
| Clay water pot | কলসি | 504 | Classic round kolshi in terracotta |
| Jute sack | পাটের বস্তা | 520 | Hessian sack with a tied neck |

Exported for Unity to `unity/SatChara/Assets/SatChara/Art/Environment/Village/` (one FBX per prop) with their textures in `Village/Textures/`. Unity hasn't imported them yet: on the Unity PC, assign URP Lit materials using the colour / normal (OpenGL; set the texture type to Normal map) / roughness maps listed per material in `art-source/village-props-summary.json`, and set the texture tiling to match (UVs are in metres).

Renders of the courtyard layout, with the Bablu mockup for scale, are in this folder.
